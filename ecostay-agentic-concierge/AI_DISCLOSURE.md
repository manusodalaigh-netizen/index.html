# AI Disclosure

EcoStay Ireland AI Travel Concierge is an AI-supported prototype. It uses customer preferences, live package data from a Google Sheet, and live weather data from Open-Meteo to suggest sustainable short-break options.

The system is intended as decision support, not a confirmed booking service. Customers can ignore the recommendation, change their preferences, or request help from a human travel advisor.

The system should not claim that an unavailable package can be booked. If live data shows zero availability, unclear pricing, or conflicting information, the customer should be told and the case should be escalated to a human.
